# **App Name**: Persona

## Core Features:

- Hero Section: Visually appealing homepage with a brief introduction and key skills.
- Projects Section: Project showcase featuring key projects with descriptions and links.
- Resume Section: Detailed resume with work experience and education.
- Contact Section: Contact form or details for potential employers/clients.
- Social Links: Links to professional social media profiles (LinkedIn, GitHub, etc.).
- Elevator Pitch Generator: AI powered "elevator pitch" generator tool for customizing introduction text, based on recent work in portfolio.

## Style Guidelines:

- Primary color: Slate blue (#708090) to convey professionalism and trustworthiness.
- Background color: Light gray (#F0F0F0) for a clean and modern look.
- Accent color: Soft olive green (#A8B493) to highlight key areas and create visual interest.
- Headline font: 'Playfair' (serif) for an elegant, high-end feel, limited to headlines or small amounts of text. Body text: 'PT Sans' (sans-serif) is appropriate for longer lines of text.
- Minimalist icons for navigation and social media links.
- Clean and responsive layout optimized for different screen sizes.
- Subtle transitions for smooth navigation and visual appeal.
